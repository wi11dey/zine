* Source Layout

 - =src= contains the Rust source for the editor
   - =src/main.rs=: winit event loop. =src/ui.rs= keeps the original egui tabs
     and scrollbar.
   - =src/render.rs=: one glutin GL context; WebRender paints the window first,
     then =egui_glow= paints the UI directly into the same framebuffer.
   - =src/editor.rs=: one persistent Source per tab, the Typst World, and editing.
     Each mutation uses Source::edit, compiles synchronously, submits a display
     list, and waits for WebRender's frame before painting. Fonts are bundled
     Typst fonts plus the existing Zine fonts. Local imports can read other tabs;
     package downloads and datetime.today are not configured.
   - =src/display_list.rs=: append pages to a caller-owned DisplayListBuilder.
     Its resource module registers monochrome font instances and images. Paths,
     complex paints, and rotated groups use individual crisp SVG image resources;
     the complete WebRender and egui layers are never rendered to intermediate
     textures. Scrolling reuses the document's display list.
 - =haskell= contains the Haskell source for
   - the internal mathematics language, =zine-math=
   - a foreign function interface for Rust to call Pandoc, for viewing e-books
